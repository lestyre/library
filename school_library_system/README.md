# 📚 برنامج إدارة مكتبة المدرسة الذكي (School Library Management System)

برنامج متكامل صُمم خصيصاً للمدارس وللأستاذ المسؤول عن المكتبة المدرسية، لإدارة استعارة الكتب والقصص مع قاعدة بيانات متكاملة ونظام تنبيهات تلقائي للطلاب المتأخرين.

---

## 🌟 الميزات الأساسية:
1. **واجهة ويب حديثة (Web Interface):** يفتح مباشرة في متصفح الإنترنت (Chrome, Edge, Safari, Firefox).
2. **قاعدة بيانات مدمجة (SQLite + Browser Storage):** حفظ فوري لجميع البيانات والعمليات دون فقدان أي سجل.
3. **متابعة الإعارات وتواريخ الاستلام والترجيع:** تسجيل تاريخ أخذ القصة وتاريخ الترجيع المطلوب وتاريخ الإرجاع الفعلي.
4. **نظام التنبيهات والإشعارات للمتأخرين:**
   - شارة تنبيهية حمراء تظهر فور تجاوز موعد الترجيع.
   - حساب تلقائي لعدد أيام التأخير لكل طالب.
   - ميزة إنشاء وطباعة/نسخ رسالة تذكير مخصصة لولي الأمر بضغطة زر.
5. **دليل الطلاب:** إدارة بيانات التلاميذ (الاسم، الصف، الشعبة، رقم الهاتف، وسجل استعاراتهم).
6. **دليل الكتب والقصص:** إدارة وتصنيف القصص والكتب وعدد النسخ المتوفرة وحالة الإعارة.
7. **إدارة وحفظ الداتابيز:** تصدير نسخة احتياطية بصيغة JSON أو أوامر SQL أو ملف `library.db`، مع إمكانية استرجاعها في أي وقت.

---

## 🚀 طريقة التشغيل:

### الطريقة الأولى: التشغيل المباشر عبر المتصفح (بدون أي برامج إضافية)
- افتح ملف `school_library_app.html` مباشرة بنقرة مزدوجة في أي متصفح ويب.
- سيعمل البرنامج بكامل طاقته مع حفظ تلقائي محلي للبيانات.

### الطريقة الثانية: التشغيل كخادم بايثون (Python Flask + SQLite Database)
1. تأكد من وجود بايثون على جهازك (Python 3).
2. افتح مجلد المشروع واكتب الأمر التالي لتشغيله:
   ```bash
   python app.py
   ```
   أو
   ```bash
   python run.py
   ```
3. سيفتح البرنامج تلقائياً في المتصفح على العنوان:
   `http://127.0.0.1:5000`
